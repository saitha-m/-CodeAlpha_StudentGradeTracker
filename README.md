# CodeAlpha Student Grade Tracker

**CodeAlpha Java Internship – Task 1**

## Project Description
The Student Grade Tracker is a Java console-based application that helps manage student names and marks. It calculates the average, highest, and lowest marks and displays a summary report.

## Features
- Enter student names and marks.
- Store student details using ArrayLists.
- Calculate average marks.
- Find the highest marks.
- Find the lowest marks.
- Display a student grade summary report.
- Validate marks between 0 and 100.

## Technologies Used
- Java
- ArrayList
- VS Code

## How to Run
1. Download `StudentGradeTracker.java`.
2. Open the file in VS Code.
3. Compile the program:

   `javac StudentGradeTracker.java`

4. Run the program:

   `java StudentGradeTracker`
